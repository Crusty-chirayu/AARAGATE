# UI UX Pro Max

For UI/UX work, use the installed design intelligence in [`.github/prompts/ui-ux-pro-max.prompt.md`](../.github/prompts/ui-ux-pro-max.prompt.md).

Use its workflow and searchable data for design systems, visual styles, typography, color, responsive layout, accessibility, interaction, charts, and Next.js/React implementation. On Windows, run its searches with `python` from the project root, for example:

```powershell
python .github/prompts/ui-ux-pro-max/scripts/search.py "responsive chat interface" --stack nextjs -n 5
```

Keep the repository's existing visual language when extending existing screens, and verify responsive, keyboard, contrast, reduced-motion, and text-wrapping behavior before delivery.
